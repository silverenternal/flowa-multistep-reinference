The converter performs these transformations on the source markdown:
- Strips the `<!-- NeurIPS Template Index -->` front-matter comment block.
- Normalizes Unicode subscripts/superscripts → `_N`/`^N` LaTeX form, then NFKD-strips any remaining non-ASCII (Greek letters → ASCII transliterations: `epsilon`, `infinity`, etc.).
- Converts headings `# …`, `## …`, `### …` → `\section{…}` / `\subsection{…}` / `\subsubsection{…}`.
- Converts bold `**x**` → `\textbf{x}`, code `` `x` `` → `\texttt{x}`.
- Wraps tables (lines starting with `|`) via `convert_table()` → `tabular`/`longtable` with `booktabs` rules.
- Inlines images `![alt](path)` → `\includegraphics[width=\linewidth]{path}` (graphicspath is `{../}{./}` so figures resolve relative to `docs/`).
- Extracts the `## References` section and re-emits it as a `thebibliography{99}` block; sanitizes cite keys to alphanumeric only.
