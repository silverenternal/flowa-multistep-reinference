### 2.5 Counterfactual methodology (verified at this audit)

The python snippet applies the Wave 209 P1 A3 / Wave 225 P4 canonical constant-offset counterfactual on the easy tier:

1. Load per-record pLDDT_mean from baseline + framework foldability.jsonl (N=1000 paired).
2. Stratify into hard / medium / easy by baseline pLDDT (Wave 198 P3 boundaries: low_33rd=34.56, high_67th=46.13).
3. For easy tier (n=330), add a CONSTANT offset to each diff equal to `+REDUCED_INTENSITY_FACTOR * |uniform_easy_mean|` = `+0.5 * 12.547` = `+6.273`.
4. This shifts the easy-tier mean from `−12.547` to `−6.273` (preserves per-record variance, since constant shift does not change sd).
5. Recompute overall d_z over all 1000 records. Result: `+0.223463` (matches `wave233-p3-tier-aware-r6.json` `k6_overall_d_z_after` to ±1e-4).

**Methodology correction:** an initial multiplicative-scaling attempt (multiplying easy-tier diffs by `0.5`) yielded d_z=+0.248458 (wrong, because scaling also halves the variance). The constant-offset method (preserves variance) is the canonical Wave 209 P1 A3 methodology and reproduces d_z=+0.2235 exactly.
