# 轮次边界核的目标保持、近似偏差与耦合反例

日期2026-11-03；推导在独立CIFAR实验运行期间完成，没有据此更改已锁定的实验臂。这里给出针对实际随机核的直接分析，区分目标保持与固定输入收缩；不是将经典耦合不等式宣称为新的一般理论。数值文件为代数恒等式核查，不是新模型实验。

## 1. 独立端点路径下的理想目标保持

令目标分布为μ，先验为ν，均有有限二阶矩。明确假设训练概率路径来自独立随机变量Y~μ、Z~ν的线性插值：μ_t=Law(tY+(1−t)Z)。令理想流映射Φ_t将μ_t推至μ。对0<m<1，定义端点再噪声核K_m(x)=Φ_m(mx+(1−m)Z′)，其中Z′~ν且独立于x。

若X~μ，则mX+(1−m)Z′~μ_m，故Law(K_m(X))=μ。证明只用插值分布与推送关系。它给出为何记忆权重必须与重启时间对应，而不证明学习得到的速度场、有限步积分或经过其他后处理的实际算法已满足上述假设。

该操作不能作为新颖性证明：Diamond Maps最新v3的第5节、式(21)–(23)已给出更一般的再噪声后继续流映射。在α_t=t、σ_t=1−t并取端点t=1时，其状态操作特化为这里的线性混合。该文还区分条件后验正确性与再噪声后生成；本节的无条件不变性不等于条件后验正确性。来源：https://arxiv.org/html/2602.05993v3 。

## 2. 学习映射的偏差—收缩递推

把实际单轮积分映射记为F_m。假设F_m在状态空间上全局L_m-Lipschitz，令ε_m=W₂((F_m)#μ_m,μ)。对任意输入分布q，使用同一Z′耦合q与μ的最优耦合，先得到混合后的W₂距离至多mW₂(q,μ)，再用映射的Lipschitz性质与三角不等式：

W₂((Kθ_m)#q,μ) ≤ a_m W₂(q,μ)+ε_m，a_m=mL_m。

实际各轮预算不同时，应写F_j、a_j=m_j L_j、ε_j，递推为D_j≤a_j D_{j−1}+ε_j，从而D_k≤(Π_j a_j)D_0+Σ_j[ε_j Π_{l>j}a_l]。若各轮a_j≤a<1且ε_j≤ε，则D_k≤a^k D_0+ε(1−a^k)/(1−a)。同一映射/时间核重复k次时可写为D_k≤a_m^k D_0+ε_m(1−a_m^k)/(1−a_m)。若真实D_0>ε_m/(1−a_m)，一次更新的这个界小于D_0；D_0小于该偏差半径时则没有改善保证。ε_m或L_m未知时不能据此直接决定部署。重启研究已经讨论收缩与新增近似/离散误差的竞争（Restart原文第4.2节）；这里是本项目核的标准耦合推论，不是对该思想的首次提出。来源：https://arxiv.org/html/2306.14878v2 。

经验输出协方差比例κ不等于mL_m，也没有给出全局L_m上界；projection-FID/Inception FID不等于图像分布的真实W₂。不能把此界直接套成已观测FID改善定理。

## 3. 高斯精确例子与错误时间起点

令ν=N(0,1)、μ=N(0,s²)，训练耦合独立。中间方差q_m=m²s²+(1−m)²，理想后段映射为F_m(x)=s x/√q_m。因此K_m是AR(1)核，系数a=ms/√q_m、b=(1−m)s/√q_m，满足a<1、a²s²+b²=s²，目标高斯确为不变分布。

若把相同混合状态交给从0开始的映射F_0(x)=sx，则a=ms、b=(1−m)s，不再具有相同目标方差。例如m=.8、s²=4，完美目标样本的方差一次后由4变成10.4。这个反例不需要模型误差，说明零时间变体在某个MNIST检查点更低FID不能作为普适正确性的依据。CIFAR简化候选是按上轮经验提出的事前验证对象；该推导不是将事后结果伪装成事前预测。

## 4. 任意训练耦合下的反例：完美模型也可能缩错

目标保持证明需要独立端点路径，不能只据“都是flow matching”就适用。取ν=μ=N(0,I)，但训练配对为Y=Z。概率路径在所有时刻都为N(0,I)，精确速度场恒为0；单次积分基线精确。此时任意后段流映射都是恒等映射，而端点混合给出X_next=mX+(1−m)Z′。

即使输入已是目标，输出方差为[m²+(1−m)²]I，严格小于I；重复核的平稳方差为[(1−m)/(1+m)]I。m=.8时一次方差.68、最终1/9，状态耦合因子却是.8<1。固定输入/同步噪声的收缩与更小的协方差，并不保证接近正确目标。最终批次质心保持也无法恢复被缩小的协方差。

这是针对可容许耦合的解析反例，不声称本次1RF或MNIST训练使用该耦合。Reflow/OT配对不能自动视为独立配对；需要逐检查点核对。即使在独立路径下，实际F_m的偏差也可能使更新变差。

## 5. 实际配置不被悄悄理想化

本项目主实例含有限步RK4/Euler、某些路径的状态截断和最终批次质心平移；这些都不能从理想核证明中删除。新的CIFAR Euler驱动沿官方epsilon约定使用物理时间τ=.001+.999u；混合权重m对应归一化起点u=m，物理时间并非精确m，差为.001(1−m)。此外官方Euler约定的增量按du而非dτ乘速度场，物理时间下另含1/.999的微小缩放差异。原始独立验证协议和源码保持不变，不为配合定理改采样过程。该偏差及学习/数值误差属于ε项的来源，需要另行界定。

批次平移δ对固定经验分布的W₂距离恰为||δ||，但它与目标距离变化的符号不定。可以用三角不等式得到附加||δ||的上界，不能推出该步骤总是改善。完整主实例的质量仍由实测组件矩阵与独立验证判断。

## 6. 复核入口与边界

工具tools/review_boundary_kernel_20261103.py输出12组闭式系数与两个反例；tests/test_boundary_kernel_review.py核对独立路径目标方差恒等式、错误时间的10.4反例、零场耦合反例及log成本面积。有限网格测试不能替代上述解析证明。论文中应保留独立耦合、全局Lipschitz、未知偏差半径、非FID结论和批次处理边界。

## 7. 训练耦合的源码对应

官方1RF代码的losses.py非reflow分支调用独立get_z0高斯采样，再构造t*data+(1−t)*z0；reflow分支直接读取保存的成对端点。sde_lib.py的reflow_flag默认False、get_z0为独立高斯，发布1RF配置噪声scale为1。原字节代码和摘要存于verification_outputs/cifar-study-20261103/rf_training_source/，固定官方提交见CONTEXT.json。这支持所选1RF发布路径与独立插值假设相符，但不是原训练运行完整manifest的恢复；不能据它把任意reflow权重也当作独立耦合。

## 高斯训练相关性的连续诊断

目标端点Y和源Z的方差分别为s²和1，Cov(Y,Z)=ρs。路径方差qρ=m²s²+(1−m)²+2m(1−m)ρs；精确后段映射为s/√qρ倍缩放。独立源刷新后的方差相对目标为q0/qρ，故ρ>0收缩、ρ<0膨胀。独立训练假设的偏离可能本身决定方向，不能都归为有限步误差。

知道真实条件分布时，用Z′=(ρ/s)X+√(1−ρ²)ξ而非独立源即可恢复路径边际；缩放后方差回到s²。ρ=1时噪声系数为零、完整边界核为恒等，不能据此宣称产生有效新探索。一般速度场不能直接提供训练条件端点采样器，不能把这个解析修正写成现成通用算法。

CPU脚本`tools/review_coupling_continuum_20261103.py`枚举s=.5/1/2、m=.2/.5/.8、ρ=−.5/0/.5/1共36组，逐组核对条件刷新方差恒等式；结果为`verification_outputs/manuscript-selfcheck-round5-2026-11-03/GAUSSIAN_COUPLING_CONTINUUM.json`。这是解析例子的有限参数数值核查，不是数学证明、新训练重复、GPU实验或独有理论创新。
