# Wave 246 P3 — BF01 sensitivity to Cauchy prior scale

**Inputs:** `verification_outputs/wave230-p2-real-4arm-per-record.csv`  
**Method:** JZS Bayes factor (Rouder et al. 2009, eq. 1) for the 
paired t-test with Cauchy prior on effect size at three scales 
(0.707, 1.0, 1.414); BF01 = 1/BF10.  
**Output:** `verification_outputs/wave246-p3-bf01-sensitivity.csv`

## 1. Methodology

The JZS BF10 (Rouder et al. 2009, equation 1, validated against JASP 
and the BayesFactor R package) is computed for a paired t-test with 
Cauchy prior on the standardized effect size d at scale r::

```
BF10 = int_0^inf (1 + N*g*r^2)^(-1/2)
              * (1 + t^2 / ((1 + N*g*r^2) * df))^(-(df+1)/2)
              * (2*pi)^(-1/2) * g^(-3/2) * exp(-1/(2g)) dg
       / (1 + t^2/df)^(-(df+1)/2)

BF01 = 1/BF10   # evidence for H0 (zero mean difference)

df = N - 1    # degrees of freedom (N pairs)
r  = Cauchy prior scale on effect (delta)
```

Wagenmakers' rough guideline:

| BF01 | Interpretation |
|------|----------------|
| > 100 | extreme evidence for H0 |
| 30 - 100 | very strong evidence for H0 |
| 10 - 30 | strong evidence for H0 |
| 3 - 10 | moderate evidence for H0 |
| 1 - 3 | anecdotal evidence for H0 |
| 1/3 - 1 | anecdotal evidence for ALT |
| 1/10 - 1/3 | moderate evidence for ALT |
| < 1/10 | strong evidence for ALT |

## 5. Interpretation

The JZS BF01 is invariant to the Cauchy prior scale for cells with 
extreme evidence either way (BF01 > 100 or BF01 < 0.01) because 
the data dominates the prior in those regimes. For cells in the 
moderate band (3 < BF01 < 30), the prior scale materially affects 
the BF01 value and may flip the strong-H0 verdict. The sensitivity 
sweep quantifies how many cells are robust to the choice of Cauchy 
prior scale.
