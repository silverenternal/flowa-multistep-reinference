## How to use this folder for reviewer verification

The figures are already inlined in the TNNLS PDF (`docs/drafts/paper-flat-ieeetran.pdf`); reviewers do not need to access this folder to view the figures. This folder exists for:

1. **SHA-256 verification of frozen figure binaries** (against any post-freeze edits)
2. **Source-rendering provenance** (via `MANIFEST.md` cross-references)
3. **Out-of-band archival** (Zenodo data deposit companion)

```bash
# Re-hash everything under paper-figures/
(cd paper-figures && find . -type l -print0 | sort -z | while IFS= read -r -d '' link; do
  target=$(readlink -f "$link")
  if [ -f "$target" ]; then
    sha=$(sha256sum "$target" | awk '{print $1}')
    echo "$sha  ${link#./}"
  fi
done) > /tmp/paper_figures_recomputed.sha256

# Compare against paper-figures/SHA256SUMS
diff <(awk '{print $1, $2}' paper-figures/SHA256SUMS | sort) \
     <(sort /tmp/paper_figures_recomputed.sha256)
```
